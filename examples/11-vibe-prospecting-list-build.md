# Vibe Prospecting List Build

Build a 25-contact ICP list with Vibe Prospecting, preview first, then draft a 3-touch outbound opener pack.

## Workflow

### Step 1 — Connect and confirm ICP

```
Read strategy/brand.md for ICP.
Confirm we will use the Vibe Prospecting MCP for list building.
If the MCP is not connected, show install guidance for vibeprospecting.ai and stop.
```

### Step 2 — Sample preview

```
Using vibe-prospecting-enrichment, preview 5–10 contacts matching our ICP
(titles + seniority + firmographics from strategy/brand.md).
Show the translated filters and the sample table before exporting.
```

### Step 3 — Export and personalize

```
After approval, export 25 contacts (email enrichment; no phone unless asked).
Hand off to outbound-email-strategy for a 3-email sequence using real enrichment signals.
Save drafts under content/email/drafts/ and update PROGRESS.md.
```
